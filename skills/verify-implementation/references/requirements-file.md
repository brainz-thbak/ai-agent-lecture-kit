# 검증용 요구사항 파일

요구사항은 UTF-8 Markdown 파일로 전달한다. 파일 첫 부분의 메타데이터에 작업을 식별하는 `task_id:`를 최상위 키로 한 번 적는다. 검증에는 문서에 기록한 ID를 사용한다.

```markdown
---
task_id: WORK-014
---

# 보관된 프로젝트 조회

- REQ-01 — 보관 포함을 켜면 권한이 있는 보관 프로젝트도 표시한다.
- AC-01 — 활성 프로젝트와 보관 프로젝트가 있는 상태에서 보관 포함을
  켜면 두 프로젝트가 모두 표시된다.
- AC-02 — 목록의 보관 포함 기본값은 꺼짐이다.
```

ID는 글자나 숫자로 시작하는 한 줄의 토큰이다. 뒤에는 글자, 숫자, 점, 밑줄, 콜론, 하이픈을 쓸 수 있다. 값 전체를 따옴표로 감싸도 된다.

스킬 폴더에서 호출자가 실제로 전달한 경로를 읽는다.

```sh
node scripts/read-requirements.mjs "/path/to/requirements.md"
```

성공하면 `task_id`, `requirements_file`, `requirements`가 들어 있는 JSON을 출력한다. 입력이 잘못되면 오류 사유를 출력하고 종료 코드 2를 반환한다.
